# Kodebua

Kodebua er en nettside for unge som trenger hjelp med programmering. Brukeren kan få hjelp fra chatboten Kodebot, finne hjelpere, se priser og fylle ut et bookingskjema.

## Teknologier

- HTML
- CSS
- JavaScript
- Google Fonts
- Figma

## Funksjoner

- Chatbot og programmeringshjelp
- Filtrering av hjelpere
- Priser og booking
- Programmeringstips
- Tilpasset PC og mobil

_Nettsiden er en prototype. Booking sender ikke ekte bestillinger._
